# HomeOffice Network Guardian

### Security Assessment Tool für Homeoffice-Arbeitsplätze

## Warum dieses Projekt?

Homeoffice-Arbeitsplätze gehören heute zu den häufigen Angriffszielen. Unsichere WLAN-Netzwerke, fehlende VPN-Verbindungen oder falsch konfigurierte Sicherheitseinstellungen können Unternehmensdaten gefährden.

Der HomeOffice Network Guardian unterstützt Mitarbeitende dabei, grundlegende Netzwerk- und Sicherheitsrisiken schnell zu erkennen und konkrete Handlungsempfehlungen abzuleiten.

## Projektbeschreibung

Der HomeOffice Network Guardian ist ein Python-Tool zur Bewertung der Sicherheit von Homeoffice-Arbeitsplätzen.

Das Programm analysiert verschiedene sicherheitsrelevante Windows- und Netzwerkeinstellungen und berechnet daraus einen Security Score. Anschließend werden erkannte Risiken sowie konkrete Handlungsempfehlungen ausgegeben.

---

##  Funktionen

- Computername erkennen
- Private IP-Adresse erkennen
- WLAN- oder LAN-Verbindung erkennen
- VPN-Verbindung prüfen
- Windows-Firewall prüfen
- Netzwerkprofil (Public/Private) prüfen
- DNS-Server anzeigen
- Standardgateway (Router) erkennen
- Security Score berechnen
- Sicherheitsrisiken erkennen
- Handlungsempfehlungen ausgeben
- Sicherheitsbericht als TXT-Datei erstellen
